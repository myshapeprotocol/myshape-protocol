# MyShape Protocol

[![CPS-0001](https://img.shields.io/badge/CPS-0001-v1.0--RC-gold)](https://github.com/myshapeprotocol/myshape-protocol) [![License](https://img.shields.io/badge/license-Apache%202.0-blue)](https://github.com/myshapeprotocol/myshape-protocol/blob/master/LICENSE) [![Research](https://img.shields.io/badge/research-Continuity%20Lab-00b4ff)](https://github.com/ContinuityLab-Org)

**The Sovereign 3D Identity Layer for the Decentralized Human.**

MyShape is the first implementation of [CPS-0001](https://github.com/myshapeprotocol/myshape-protocol), the Continuity Protocol Standard — an engine-independent protocol for motion-signature verification and zero-knowledge presence proofs.

## Protocol

- **AI-native identity** — motion-signature verification resistant to AI simulation
- **Zero-knowledge presence** — prove humanity without revealing identity
- **On-device processing** — zero raw data leaves the device
- **Engine-independent** — any sensor, any team can produce a valid receipt
